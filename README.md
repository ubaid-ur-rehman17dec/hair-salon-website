# ✂️ HairCut - Luxury Unisex Hair Salon & Beauty Web App

A modern, responsive, high-performance **React Web Application** for **HairCut Unisex Salon**, built with **Vite**, **React Router v6**, **Bootstrap 5**, and custom CSS. 

Features premier grooming services for **Gents** and luxury beauty & **Bridal Makeup** packages for **Ladies**.

---

## ✨ Features

- 🌟 **Modern Unisex Salon Experience**: Full service support for Gents (haircuts, beard trims, shaves, color) and Ladies (bridal makeup, styling, facials, manicure/pedicure).
- 🖼️ **Interactive Clear-Photo Reveal Cards**: Service cards featuring high-res imagery that transitions on hover to reveal crystal clear photography.
- 📅 **VIP Appointment Booking Modal**: Interactive modal dialog allowing customers to select date, time, barber/stylist, and service.
- 🎨 **Luxury Light & Dark Harmonious Theme**: Crafted with Oswald & Roboto typography, red (`#EB1616`) glowing accents, glassmorphic headers, and smooth micro-interactions.
- 📱 **100% Mobile Responsive**: Mobile drawer navigation, sticky header with backdrop blur, and touch-friendly sliders.
- ⏱️ **Live Working Hours & Contact Hub**: Embedded weekly schedule, live open status badge, and direct call/location links.
- 🎵 **Social Media Integration**: TikTok, Facebook, Instagram, and YouTube social channels.

---

## 🚀 Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 5
- **Routing**: React Router v6
- **Styling**: Bootstrap 5 + Custom Vanilla CSS
- **Icons**: FontAwesome 5 + Bootstrap Icons

## 🛠️ Quick Start & Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/hair-salon-react.git
   cd hair-salon-react
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

4. **Build for Production**:
   ```bash
   npm run build
   ```
